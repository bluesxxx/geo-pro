四款工具，各自部署

两个 SaaS（PackMeta / DocuConsist）已在线托管；两个可自托管工具（GEO PRO / salesbuddy）支持本地部署， 数据完全自持。下方给出各自的部署路径。

0 本 Hub 站（JetSocio.com）

纯静态，托管在 Cloudflare Pages；首屏体检调用轻量审计 API（Railway）。

1. Cloudflare Pages

Pages 项目 → 上传 hub/ 目录（index.html + assets/）→ 绑定 jetsocio.com 主域

2. 审计 API（Railway）

New Project → GitHub bluesxxx/geo-pro → 构建目录 services/audit-api（Dockerfile）
镜像 php:8.4-cli，监听 8080，无持久卷、无环境变量
部署后得到 URL（如 audit-api.up.railway.app）→ CNAME: audit-api.jetsocio.com

3. 指向 API

修改 hub/assets/report.js 顶部 AUDIT_API_URL 为你的审计 API 地址

1 GEO PRO（本地自托管）

Laravel 12 完整栈：PostgreSQL + pgvector、Redis、Horizon 队列、Reverb WebSocket。含 /audit 真后端体检（SSRF 网关 + 规则评分）。

git clone https://github.com/bluesxxx/geo-pro.git
cd geo-pro
cp .env.example .env && composer install && npm install
php artisan key:generate && php artisan migrate --seed
php artisan serve           # 前台 /audit 体验体检
npm run dev                 # Vite

2 salesbuddy（本地自托管）

自托管 WhatsApp CRM（wacrm 分支，Next.js + Supabase）。Hub 仅展示，不品牌化；部署请参照上游文档。

上游项目: https://github.com/wacrm/wacrm   （MIT，Arnas Donauskas）
自托管要求: Next.js 16 + Supabase（Auth / Postgres / Realtime）

3 PackMeta（已上线）

3D 装箱优化 SaaS，前端 Cloudflare Pages、后端 Railway，已托管，无需本地部署。

线上: https://packmeta.pages.dev/
模式: 免费试用（上传装箱单 → 秒级 3D 装柜方案）

4 DocuConsist（已上线）

外贸单证一致核验 SaaS，已托管（前端 Cloudflare、后端 Railway），免费免登录。

线上: https://docuconsist.com/
模式: 免费 · 免登录（上传单据 → 30 秒跨单比对）
