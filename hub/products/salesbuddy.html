01它能帮你解决什么

在「转化」这一环，跨境卖家最常见的问题是：询盘散落在个人 WhatsApp、跟进靠记忆、订单在聊天里溜走。SalesBuddy 把分散的对话收进统一的销售工作台。

  • ✓ 多号码 / 多坐席统一视图

  • ✓ 消息已读 / 未读状态

02私有化部署

SalesBuddy 不单独 fork，而是直接基于上游开源项目 wacrm 进行私有化部署——你拥有完整的代码、数据与账号体系，没有中间商抽成。

1
准备环境：一台装有 Docker 的服务器，开放 80/443 端口并准备一个域名。
2
部署 wacrm：拉取上游仓库，按其官方文档一键启动（SalesBuddy 即 wacrm 的私有化实例）。
3
接入 WhatsApp：在 Meta 后台创建 WhatsApp Business 应用，填好 Webhook 与令牌。
4
配置团队：创建坐席、分配号码、导入客户，即可开始收件与跟进。
# 1. 获取上游开源仓库
git clone https://github.com/ArnasDon/wacrm.git
cd wacrm

# 2. 按官方文档启动（Docker 编排）
docker compose up -d

# 3. 浏览器访问并绑定你的域名 + WhatsApp Business API
关于「SalesBuddy」与「wacrm」：SalesBuddy 是 JetSocio 对这套私域 CRM 能力的命名包装，底层即开源 wacrm。我们不在上游之外另起 fork，而是建议你直接部署 wacrm 并自行保留品牌定制空间，最大化代码可追溯性与安全更新能力。
